# Building Ledger Mobile PWA — GitHub Pages subpath package

Version: `2026.11.14-01`

Prepared for: `https://emadmadi80.github.io/Building-Ledger/`

Upload the **contents of this folder** directly to the root of the GitHub repository. `index.html` must be directly in the repository root. Do not upload the outer folder and do not use a `public` folder.

All assets use relative URLs and the manifest/service worker are scoped to the repository folder. Enable GitHub Pages from `main` and `/ (root)`, then open the URL in Chrome Android and choose **Install app** or **Add to Home screen**.

The same files automatically use the expanded layout on computer screens and the compact mobile layout on phones. Do not open `index.html` using `file://`.
